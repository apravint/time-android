# ⏰ Time - Fullscreen Digital Clock App (`v1.0.0`)

[![GitHub Release](https://img.shields.io/github/v/release/apravint/time-android?color=magenta&label=Latest%20Release)](https://github.com/apravint/time-android/releases/tag/v1.0.0)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Android Min SDK](https://img.shields.io/badge/Android-7.0%2B%20(API%2024)-brightgreen)](https://developer.android.com)

**Time** is an ambient full-screen digital clock app for Android featuring top-notch custom Google Fonts typography, dynamic neon glow themes, screen keep-on wake lock, and low-brightness night dimming.

Developed by **Ayyappa Pravin** (<apravint@gmail.com>).

---

## ✨ Features

- 🔤 **8 Top-Notch Google Fonts**: Orbitron, Outfit, JetBrains Mono, Monoton, Space Grotesk, Cinzel, Playfair Display, and 8-Bit Arcade 2P.
- 🎨 **7 Ambient Glow Color Themes**: Cyber Neon, Tokyo Night, OLED Stealth, Luxury Gold, Emerald Matrix, Crimson Red, and Nord Frost.
- 📱 **Immersive Fullscreen Sticky Mode**: Auto-hides system navigation bars for desk/bedside display setups.
- 💡 **Wake-Lock & Night Mode**:
  - Keep screen permanently on via `FLAG_KEEP_SCREEN_ON` bridge.
  - Low-brightness night mode to prevent OLED burn-in while sleeping.
- ⚡ **Battery & Date Telemetry**: Real-time battery indicator (`⚡ 100%`) and full calendar date display.
- ⏱️ **12h/24h & Seconds Toggles**: Fully customizable time formats.
- 🖼️ **Custom Vector Launcher Icon**: Neon cyan clock dial vector launcher icon (`ic_launcher.xml` & adaptive XMLs).
